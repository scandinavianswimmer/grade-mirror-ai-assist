# Plan 01-05 — Remove mock injection; render verified output

## Objective
Make the UI show ONLY what the engine actually produced. Strip the `Math.random()` mock scores and hardcoded feedback/vocabulary from the production path, render verified annotations, and present explicit error / low-confidence / unplaced-feedback states instead of fabrications. This is the user-visible payoff of "Trust the Grade."

## Context
`SubmissionDetail.tsx` (~1,640 lines) calls the real `generateGradingFeedback` (~L465) and `resolveAnchors` (L148), but `processAIResponse` (~L663-712) overlays `Math.random()` scores and hardcoded feedback tiles + vocabulary cards regardless of real AI output. A legacy `dangerouslySetInnerHTML`/`contentEditable` renderer also coexists with the span-based `GrammarlyAnnotations`. The client must now consume the 01-03 structured `GradingResult` and the 01-04 anchoring result (with `matched` flags + unmatched list).
