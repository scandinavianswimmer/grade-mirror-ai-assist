## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Importing `./supabase` in a `src/lib` unit-tested module | The supabase client touches `localStorage` at import time → crashes vitest's node env ("no tests"); cost a refactor mid-task | blocking | Keep pure logic in a supabase-free module (e.g. `sampleEssays.ts`) and isolate DB I/O in a sibling `*Api.ts` (e.g. `sampleEssaysApi.ts`). Tests import only the pure module. |
| Putting new migrations in `supabase/migrations/` | The legacy dir is dead; `migrations_v2/0001_baseline` "replaces migrations/". A migration placed there will never apply | blocking | New migrations go in `supabase/migrations_v2/` with `NNNN_name.sql` numbering (next is 0022). |
| Self-merge / direct push to main | `gh pr merge 14` and `git push origin main` are denied by the auto-mode classifier | blocking | Founder merges PR #14; agent uses PR flow only. |
| Deploy gated | `supabase functions deploy` (esp. `--no-verify-jwt`) is permission-denied to the agent | blocking | Founder deploys; agent verifies in-browser. |
| Trusting RTK-cached git reads | `rtk` caches `git log/status/rev-parse`; stale results mid-session | advisory | Use `rtk proxy git <cmd>` to bypass the cache when verifying state. |
| Adding a column to a page-gating `.select()` | A column absent pre-migration makes the whole select error and breaks page load | advisory | Fetch new/optional columns in a separate best-effort query (see SubmissionDetail `finalized_by`), or `select('*')`. |
